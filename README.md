# Radar

A responsive, interactive weather dashboard built with plain HTML, CSS, and JavaScript. No build step or dependencies required.

## Run locally

Open `index.html` in a browser, or serve this folder with any static web server. The app can also be hosted with GitHub Pages from the repository's `main` branch and root folder.

## Features

- Responsive current-weather dashboard and animated radar-style map
- Hourly forecast cards
- City search for San Francisco, New York, London, Tokyo, Manila, Los Angeles, Singapore, and Paris
- Celsius/Fahrenheit toggle, radar pause control, and map zoom buttons
- Optional browser location permission prompt

## Demo data

Weather values and precipitation on the map are sample/demo content, not live observations. Location search only supports the cities listed above. To provide real forecasts and radar imagery, connect a weather API and replace the sample data in `app.js` and the illustrative map layers in `index.html` / `styles.css`.
